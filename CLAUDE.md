# Selficient — working rules

Read `plans/build-plan-v1.md` before touching code. It governs architecture, patterns, security, performance, testing and the per-feature workflow. `product/design-direction.md` governs every visual and copy decision.

## Non-negotiables

- **Never caveman the app.** Every user-visible string is a whole, explicit sentence in the interface's voice (sentence case, plain verbs, no filler, no exclamation marks, no apologies). Pin wording with tests.
- **Dapper, never EF Core.** No database in v1 at all.
- **No framework, bundler, transpiler or preprocessor on the front end.** Modern platform CSS and JS only. No inline script or style; CSP nonces are the only exception and are injected by the tag helper.
- **100% line and branch coverage per production assembly.** `./build/run-tests.ps1` is the gate locally and in CI. Exclusions only as documented in `docs/coverage-exclusions.md`.
- **Every feature starts with a threat model** in `docs/threat-models/<feature>.md` and failing adversarial tests. Nothing merges without them and a security review pass.
- **Dependency rule:** Web → Application → Domain; Infrastructure → Application; Infrastructure is referenced only from the composition root. Architecture tests enforce it.
- **No personal data about readers on the server in v1.** This is about the households who use the site, and it exists to make a casual visitor comfortable engaging with it: no accounts, no cookies, no analytics, postcodes logged as outward district only, photos processed in memory and discarded. **It is not a rule about the back office.** Operators are staff: their accounts, their sign-ins with the address and the agent they came from, and every change they make are recorded in full, because a security surface without that cannot be investigated. Do not apply the reader's rule to the people running the platform.
- **Secrets are environment variables.** Never in the repo, never in workflows.
- **The rules engine is deterministic and owns Days Ready and the plan.** AI explains, counts and answers; it never computes.

## Gotchas already paid for

- A `<script type="importmap">` in Razor must be written `<!script …>` to opt out of the framework's import-map tag helper, which strips the type; stamp the nonce by hand from the injected `CspNonce`.
- Nonces are URL-safe base64 because Razor's attribute encoder rewrites `+`, `/` and `=`.
- No `style="…"` attributes anywhere, even in demos: CSP blocks them. Map state to data attributes and select on those.
- `color-mix(in oklab, …)` for tints; oklch interpolates hue towards white's hue of 0 and turns green tints pink.
- `const decimal` emits a static constructor the tests never run; use a static property.
- `dotnet test … --results-directory` must come before the `--` that hands arguments to the testing platform.
- A vendored stylesheet loaded by a plain `<link>` is unlayered and beats every `@layer`; overrides for it (the MapLibre chrome in `map-chrome.css`) must be unlayered too, imported last from `app.css`, and at least as specific as the library's own selector.
- A `try` block that returns from inside leaves its closing brace uncovered; assign inside the `try` and return after it.
- `tsc` refuses `declare module "/lib/…"` (rooted names count as relative); route vendored libraries through the import map by bare specifier and type them in `types/*.d.ts` with a `paths` entry.
- Shell `perl -0pi` substitutions break on `|` and on `$1` followed by a space and a digit; use the Edit tool for anything but one-line `sed`.
- Razor reserves `<text>`; an SVG `<text>` element must be emitted with `Html.Raw` from constant content (the month labels), never from user data.
- The Anthropic C# SDK (13.x) sends the key as `Authorization: Bearer`, not `x-api-key`, and its message types are `UserMessageParam` / `ImageBlockParam { Source = new Base64ImageSource }`; a stub must match the bearer header. Reflection on the SDK assembly from PowerShell 5.1 fails (net8 assembly); grep the DLL bytes or write a throwaway console probe in the scratchpad.
- SkiaSharp decodes a PNG with garbage pixel data as "incomplete" rather than failing; a palette PNG with no PLTE chunk is the input that opens as a codec and fails to decode.
- `.webmanifest` is not in the framework's content-type map; it is mapped in the pipeline. The worker template under `wwwroot` is never listed in the shell because the shell scan covers only `css`, `js`, `lib`, `img` and `fonts`.
- `WebApplicationFactory` finds the content root through the test project's manifest; a runner started from elsewhere (the load project, the E2E fixture) needs `UseSolutionRelativeContentRoot("src/Selficient.Web", "Selficient.slnx")`, fully qualified because two extension classes share the name. `StartOnKestrel()` on the factory gives a real port for Playwright and NBomber.
- Every option is range-validated at startup; a fixture that lifts a rate limit must stay inside the range (`AiPerMinute` tops out at 1,000) or the host refuses to start with a message that looks like a test failure.
- A service worker's first `controllerchange` on a device is not an update; reloading on it reloads every first visit and destroys any script context a test is evaluating in. `shell.js` only reloads when a worker is replaced.
- axe samples colours mid-animation; audit after `document.getAnimations()` has finished or the lifting Days Ready figure reports a contrast failure.
- Lantern is a fill colour. Lantern as text is `--c-lantern-ink`; the bright value fails 3:1 on the light ground and the plan page only passed because the contour band hides the background from axe.
- Stylesheets are linked from the layout one per layer, each wrapped in `@layer name { … }`, with `app.css` first to fix the order. Do not reintroduce `@import`: it chains round trips on a slow phone.
- Fonts are WOFF2 subsets made by `build/subset-fonts.mjs` from the foundries' files, which are not in the repo; `tokens.css` declares the narrowed weight and width ranges, so a new weight needs a new subset.
- `Short` is a type name to CA1720 and cannot be an enum member; the board uses `Rationed`. An enum `switch` expression compiles to a jump table with a branch no valid value reaches, so coverage never hits 100% on it: use a dictionary lookup for enum-to-value maps.
- A test that drives a simulation must be written from the engine's own output, not from the sentence in the design document: the probe in the scratchpad (`dotnet run` against the Domain project) is how the M12 goldens were read before they were pinned.
- `TimeProvider.TimestampFrequency` is the Stopwatch frequency: ten million a second on Windows, a thousand million on Linux. A test clock must override it (the TestKit `ManualClock` uses TimeSpan ticks) or an advance of a day is a hundred days on the ubuntu runner, which only CI sees.
- Look at the site, do not only test it. A desktop-width screenshot of every page is part of every E2E run (`artifacts/screens`); open them before calling a milestone done. The M0 to M10 build shipped a phone column on a 1500 px screen because nobody did.
- `dotnet run` on the web project locks `Selficient.Web.exe`; stop it before `dotnet build` or the build fails to copy the apphost.
- Shouldly's `ShouldContain(string, string)` second argument is the comparison, not the message; write `customMessage:` by name or the assertion silently compares the wrong thing.
- Fields a fragment endpoint re-posts must carry the page model's prefix (`Form.Postcode`, `Form.Dependencies[0].Name`); a bare `Postcode` binds to nothing and every redraw is a 400 with the first required-field sentence.
- A data attribute used as a selector (`data-action-id`) must name one thing; a second list that reused it broke the first's `querySelectorAll`. Give each list its own attribute.
- A compound predicate over an ordered list (`First(b => b.Source == house && b.Season == season)`) leaves a branch no input can reach when the matching item is always first; store the value instead of searching for it.
- A full-bleed band inside the centred column: `body` is an inline-size container and the band is `inline-size: 100cqi; margin-inline-start: calc(50% - 50cqi)`, padded back to the column. A `box-shadow: 0 0 0 100vmax` with `clip-path` does not widen the page but anything positioned past the box does, and `overflow-clip-margin` counts toward the scroll width; `overflow: clip` without a margin is the fence.
- An SVG sprite used through `<use href="/img/marks.svg#id">` cannot carry a `<style>` element (the CSP has no inline style allowance); put the stroke and fill as presentation attributes on each `<symbol>`. Custom properties do inherit into the `<use>` shadow tree, so `fill="var(--c-lantern, #E8A33D)"` follows the theme.
- A ternary in a Razor view is a branch the gate counts, and a view only renders what the tests post; put the choice in a helper (`BoardCopy.Unit`) and pin it there.
- The load harness hosts the site in a console project: declare `ServerGarbageCollection` there or it measures the workstation collector under the web server's allocation and every scenario collapses together.
- A page that pre-renders every variant for an in-place switch pays for all of them on every request; render the one in view and post for the next.
- A fragment that redraws itself must not be the only place the script reads the antiforgery token from: when the scenario form left the board fragment, `redraw` found no token and returned silently, and every journey that ticked a box failed with no error anywhere. Read the token from the document.
- The catalogue's links are the commercial surface. Never guess a shop's search address: open it. `./build/check-links.ps1` opens every pick in Chromium and reports; it runs weekly in Actions. Argos and Screwfix wall off a headless browser, Safelincs and Halfords render search by script, so picks there cannot be checked and were moved.
- `perl -0pi` with a `|` delimiter mangled a file for the third time this project (a regex alternation inside the replacement). Use the Edit tool for anything with a pipe in it; the rule above is not a suggestion.
- Lighthouse runs from the scratchpad (`npm install lighthouse@12`, `CHROME_PATH` to Playwright's Chromium, `--ignore-certificate-errors` against the dev certificate); it is not in the gate because its scores are simulated.
- SQLite gives Dapper a `long` for every `INTEGER` column; a record parameter declared `int` fails materialisation at the first query ("a parameterless default constructor or one matching signature … is required"), not at compile time. Declare `long` and cast.
- `BackgroundService.StartAsync` on the .NET 10 host returns before `ExecuteAsync` has run its first line, so anything a test does straight after `StartAsync` races the service. Create the `PeriodicTimer` before the first `await` so a tick is never lost, and in tests wait for an observable (the catalogue's `IsLoaded`) before advancing a `FakeTimeProvider`.
- Razor encodes an apostrophe in `@value` as `&#x27;`; a test that asserts a notice sentence with one must assert the encoded form, while literal markup keeps the plain character.
- `perl -0pi` and `sed` substitutions whose replacement contains a Windows path or `\x27` lower-case or eat the rest of the line (`\L`, `\a`, `\t` are escapes); write the replacement to a file and use `sed '59r file'`, or use the Edit tool.
- A heredoc through the Bash tool (`cat <<'EOF'`) collapses `\` to `\` and turns `\x27` and `\L` into their escapes even when the delimiter is quoted; a script or source file with a backslash in it goes through the Write tool, never a heredoc.
- A malformed at-rule (`@media@media`, from a bad substitution) makes the browser drop the whole block with no error anywhere, and the landing page shipped in its phone column for a day because nothing checked the stylesheets. `npm run check` now runs stylelint over `wwwroot/css` as well as tsc and ESLint; the E2E `Layout` tests pin the desktop hero's two columns and the figure's cut so a dropped block fails a test rather than waiting for someone to open a screenshot.
- `margin-inline: auto` on a grid item cancels its stretch and shrink-wraps it to its content, and an SVG with only a `viewBox` has an intrinsic width of 300px: together they shrank the hero's kitchen table to 300px inside a 467px column. Give such an item `inline-size: 100%` alongside the auto margins.
- A variable font renders every weight and width identically when the subset was cut without those axes, silently. Measure two spans at different weights in a test rather than asserting the declaration.
- `HybridCache` answers the caller before it writes the distributed cache; a test that counts rows in `dbo.cache` straight after a `GetOrCreateAsync` sees none. Poll for the row, or drive `IDistributedCache` directly when the question is whether the backend works. A failing backend write is logged and swallowed by the framework, so with no logger registered it is silent.
- In `CREATE TABLE`, `COLLATE` comes straight after the type and before `NOT NULL`; the other order is "Incorrect syntax near the keyword 'COLLATE'" at the first migration, not at build.
- `ProtectKeysWithDpapi` is Windows-only to CA1416 and the analyzer only accepts `OperatingSystem.IsWindows()` as a guard, not a bool you pass in; call it from the composition root inside that guard, where coverage is already excluded, rather than wrapping it for a test.
- NSubstitute's `Returns(_ => throw …)` on a `Task<T>` member is ambiguous between the task and non-task overloads; use `ThrowsAsync(new …)` from `NSubstitute.ExceptionExtensions`.
- A test database is dropped by killing its sessions first (`sys.dm_exec_sessions`) and retrying: `SET SINGLE_USER WITH ROLLBACK IMMEDIATE` alone loses the race to a pooled connection that was still closing, and the drop fails with "currently in use". `TestDatabase` does this; nothing else should create databases.
- A suite that throws in `InitializeAsync` never reaches `DisposeAsync`, so a crashed run leaves `selficient_test_%` databases on the server; `sqlcmd` with a `DROP DATABASE` loop over `sys.databases` clears them, and a clean run ends with none.
- A bare `throw;` inside a `catch` of an async method leaves a branch in the state machine that no test can take; rethrow with `ExceptionDispatchInfo.Throw(exception)` instead, which is a call and keeps the stack.
- `HybridCache` serialises what it keeps even in process, so a value whose type has no deserialising constructor (a `KitPick`) throws on the first read-back with "Deserialization of types without a parameterless constructor…"; keep such values in a plain keyed memo, or give the cache a shape made for it.
- A `BackgroundService` that waits on a `PeriodicTimer` should make the timer in `StartAsync`, on the caller's thread, before calling `base.StartAsync`; the host runs `ExecuteAsync` off that thread and a test's `Advance` before the timer exists is a tick nobody receives.

## Conventions

- .NET 10, `Selficient.slnx`, central package management, warnings as errors, analyzers at latest-Recommended.
- Tests: xunit v3 on Microsoft.Testing.Platform, Shouldly, NSubstitute. Name tests as prose: `Adding_water_never_lowers_days_ready`.
- Commits: imperative subject, body explains why, trailer `Co-Authored-By: Claude Fable 5.1 <noreply@anthropic.com>` when Claude authored.
- Branches: `development` for integration, `main` deploys to production. No staging; test locally.
- `repeat(auto-fit, minmax(26rem, 1fr))` does not shrink below its minimum, so a track wider than a phone makes the page scroll sideways and the E2E sideways-scroll assertion is what catches it. Write `minmax(min(26rem, 100%), 1fr)`.
- `auto-fill` lays empty tracks and `auto-fit` collapses them: a three-item list on a wide monitor fills three of six `auto-fill` tracks and sits in the left half of the row. Use `auto-fit` wherever the item count is smaller than the tracks the width allows.
- A page's own `max-inline-size` silently beats `--page-max`: the plan page was capped at 66rem and the deals page at 48rem long after the page width grew. Grep for `max-inline-size` on page containers before concluding the page width is wrong.
- An ASP.NET Core cookie with `CookieSecurePolicy.Always` is never stored by a test client on `http://localhost`; a `WebApplicationFactory` client that signs in needs `BaseAddress = new Uri("https://localhost")` or every assertion fails for the wrong reason.
- `WebApplicationFactoryClientOptions.AllowAutoRedirect` defaults to true, so a POST that redirects answers 200 with `RequestMessage.RequestUri` at the destination and no `Location` header. A helper that drives a multi-step flow must read both shapes, and must compare the landing path with the posted path to tell "moved on" from "refused and re-rendered".
- The test database belongs to the test host, not the test class, so two suites that both create an operator called the same thing collide on the unique index. Reuse the row when it is already there.
- `AddHostedService<T>()` does not register `T` for resolution; a test that wants to run the service again constructs it.
- `JsonSerializer.Serialize`/`Deserialize` fail the trimming and AOT analyzers as errors here. Use a `JsonSerializerContext` with `[JsonSerializable]` rather than a suppression.
- `step` is a reserved word to CA1716 and cannot be an interface parameter name; the operator store takes `lastStep`.
- A QR code holding a secret is drawn inline as an SVG path in the response, never served from an endpoint: the `otpauth://` address carries the authenticator's seed and a URL for it can be logged, cached or shared. `QrCode.For` builds the path; each run of dark modules on a row is one bar, not a rectangle per module.
- A QR code is always dark on white whatever the theme. One inverted in the dark does not scan.
- A grid's `gap` reaches its direct children only. A form nested a level deeper inside a panel is spaced by its own margins, which is how a submit button ended up flush against the box above it twice. Give the nested container the same grid and gap rather than reaching for a margin; the E2E `Layout` tests measure the room above every button on the operator pages.
- A `.field` is a grid, and a grid item stretched to its row stretches its own rows unless it says `align-content: start`: a number box beside a taller neighbour grew to 138px. The E2E `Layout` tests measure every single-line box on the solar and wizard pages.
- The engine names the first provider it meets as the one carrying a need, in the order of `Providers.All`. A partial fallback listed before the full provider takes the credit on days the full one is doing the work (the bin bags were named while the liners held): list the better provider first.
- A scenario condition that changes what a provider can do (the sewers stopping with the power) is a rule in `Simulation.Prerequisites`, never a sentence in the copy alone. The board is what a household acts on.
- The shipped catalogue is merged into the store on every reload by action and link. Changing a shipped pick's link makes it a new offer and leaves the old one live; hide the old one on the reviewer.
- axe refuses a `<dl>` whose groups hold anything but `<dt>` and `<dd>` (a button beside each figure), and refuses a button whose `aria-label` does not contain its visible words. A tile with a control in it is a list item, and a longer accessible name starts with the words on the button.
- A control whose count can fall to nothing under the user's own press is marked `aria-disabled`, never `disabled`: a disabled button drops the keyboard's focus the moment it empties. The handler returns early on the attribute.
- What a household says about an action is one of `have`, `plan`, `skip` in the browser's `ticks` store (`true` from before reads as `have`), posted as `Ticks`, `PlanTo` and `NotForMe`. Only `have` reaches the simulation for today; the tallies and the planned figure come back in the board fragment and the page copies text from them, it does not sum.
- The local site on 7310 runs compiled views from a copy of the build but takes its content root, and so its stylesheets and scripts, live from `src/Selficient.Web`. Editing CSS or JS that goes with a markup change breaks the running site at once, new styles on old markup, until it is restarted on the new build. Rob was demoing when the plan page's rows lost their layout this way. Restart straight after the first front-end edit of such a change, or do not start one while he is demoing.
- A `[BindProperty]` dictionary must be bound by name (`[BindProperty(Name = nameof(Amounts))]`). Unnamed, a post that carries none of its keys falls back to the empty prefix, the binder tries to read every field on the form as an entry, and the model is invalid: every plan post was refused, with no sentence that pointed at the cause.
- A household's own figure for a stock (`MeasuredStocks`, posted as `Amounts[id]`) is the truth for every plan action it counts towards, whatever is ticked. Simulate through `Possessions`, and add an action with `Possessions.Add`, which tops a counted stock up to what the action asks rather than stacking a second provider on it. A new what-if in the composer that adds to a raw set of held ids will promise a month on top of a ten-day shelf.
- A rule later in a layer's sheet beats an earlier one of equal specificity, layer or no layer: `.amount .input` lost to `.input.input--short` further down `components.css` and the box drew full width. Match the classes of the rule being overridden.
- The local site shows "The street map is not available on this server yet" unless it is started with `Map__MbTilesPath` pointing at a tiles file; SiteWise's copy is at `D:\Source\Repos\sitewise.app\tiles\os-open-zoomstack.mbtiles`. It was left off the start command, and Rob asked why the map was missing.
- A value the household may type that the framework would bind as a number (`CashRate`) is bound as text and parsed by hand, so nonsense is answered with our sentence. A nullable int that fails to bind answers with the framework's "The value is not valid" fragment.
- A web test that presses "Open every link now" must register a stand-in `IPageReader` first, as `AdminCatalogueTests` does. Without one the verifier opens thirty-odd real shops from the test run, slowly and not always successfully.
